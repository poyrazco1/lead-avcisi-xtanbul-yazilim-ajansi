# Lead Avcısı Panel v3.8 — Tikli Çoklu Seçim + Hızlı Kontrol

Bu sürüm v3.7 üzerine seçim deneyimini düzeltir.

## Yeni eklenenler

- Çoklu seçim kutularında seçili öğelerin yanında `✓`, seçili olmayanların yanında `□` görünür.
- Hızlı kontrol alanı artık sadece sayı göstermez; seçilen ana kategori, alt kategori, alt alt kategori/meslek, şehir, ilçe, serbest kelime ve manuel bölgeleri ayrı ayrı gösterir.
- Hızlı kontroldeki seçili öğelere tıklayarak ilgili seçimi tek tek kaldırabilirsin.
- Aranacak ilk 10 kelime ayrıca ön izleme olarak görünür.
- Mobilde seçim listeleri ve hızlı kontrol alanı daha okunur hale getirildi.

## Kurulum

Eski klasörün üstüne karıştırma. Yeni klasörü yükleyip `login.php` üzerinden giriş yap.

## Not

API key ve DB şifresi arayüzde düz gösterilmez. Google aramaları yine backend üzerinden gider.
