XTANBUL DIRECT PLESK v3.9

Bu ZIP doğrudan Plesk httpdocs içine çıkarılacak şekilde hazırlanmıştır.

Açıldıktan sonra:
- Site ana alan adında çalışır: /index.php
- Site admin: /admin.php
- Lead panel: /panel/login.php
- Panel sunucu kontrol: /panel/server-check.php

Giriş:
- Panel ve site admin kullanıcı bilgileri config dosyalarında hazırdır.
- Kurulumdan sonra şifreleri değiştirmeniz önerilir.

Önemli:
- /panel/app ve /panel/data klasörleri .htaccess ile korunur.
- Google API key panelde ekranda açık görünmez.
- SQL dosyası /panel/database/schema.sql içindedir.
